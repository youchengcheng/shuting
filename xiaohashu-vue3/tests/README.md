# 通知前端验证

运行 `npm test` 检查十进制序号、会话隔离、跨页签同步、旧分页加入后的已读校准、100 条分批、全部已读快照、失败保留未读、摘要单飞、SSE 分帧和评论上下文。自动更新回归覆盖进入及切回分类获取最新快照、SSE 连续提示合并、旧分页被最新快照取代、摘要先于列表返回、刷新结束与清理之间的新提示，以及账号切换和已读边界。界面已去掉已读/未读标签和手动标记按钮，打开通知仍自动同步角标；底层状态回归继续保留。

运行 `npm run build` 验证生产构建。

本机同时运行开发服务导致 Node 原生内存分配不足时，可用 `node --max-old-space-size=384 --max-semi-space-size=8 node_modules/vite/bin/vite.js build` 完成同一生产构建；本次使用该命令通过，没有停止正在运行的服务。

`profile.test.js` 验证登录 token 存在而资料缓存为空时，侧栏和账号菜单使用的本人主页路由可达；本人及指定用户的笔记子路由、资料查询、失败重试、账号切换丢弃迟到响应、访问他人不覆盖本人身份、字符串/数字 ID 一致，以及通知接口 404 的中文错误呈现。当前 `npm test` 共 44 项并全部通过：通知状态 21 项、个人主页 7 项、`notificationNavigation.test.js` 正常分页定位 9 项、`notificationPresentation.test.js` 预览展示 7 项。

真实联调使用正常应用入口（例如现有 `http://localhost:5173/`）和真实登录状态，检查“我”和账号菜单“我的主页”、资料及笔记加载、通知 API 和 SSE。下面的离线夹具不替代正常应用验证。

界面验证复用现有开发服务，打开 `http://localhost:5173/tests/preview.html`，无需另起测试端口。此夹具装载生产 App、Router、Pinia 和组件，并在夹具内拦截全部 Axios 与 SSE 请求；合成账号和通知只在内存中，生产入口没有夹具逻辑。刷新时重新打开该夹具 URL。

夹具支持 `?case=empty`、`?case=error`、`?case=deleted`，分别验证分类空态、首屏失败和评论目标删除；`?case=deep` 提供 30 条一级评论、14 条回复，目标位于一级评论和回复的第 3 页，用于检查定位及中间缺页补齐；`?case=picture` 用于检查图片评论预览和手机定位。默认有三类逐条通知、失效内容、分页和超过 99 的未读角标，以及目标评论所在的正常评论区。

分类选中背景与按钮对齐，过渡为 200ms，手机页面无横向溢出；文字预览最多 32 字后省略。评论点赞展示被点赞的原评论，新评论和回复展示新产生的评论；评论有图片时只展示该评论图片，不回退到笔记标题或封面。更多菜单和关于书亭弹窗也已确认没有来源推广内容。

通知列表及标题桌面宽度为可用宽度的 80%，居中，分类工具栏也居中；手机保持全宽适配。行高已恢复调整前的上下留白（桌面 20px、手机 18px）。最新通知列表截图位于 `.impeccable/review/notification-context-desktop.jpg`、`notification-context-mobile.jpg`（375）；`notification-width-*`、`notification-final-*` 为历史截图，`notification-compact-*` 是已撤销的行高方案。

点击通知始终打开完整笔记和正常评论列表，通过后端 `rootCommentId/rootPageNo/childPageNo/rootPageSize/childPageSize` 定位目标，滚动后高亮。目标评论按自身内容高度在滚动可视区域居中，排除一级评论的回复子树；图片加载后的定位校准同样居中，首尾受实际滚动边界限制，超长评论优先保证开头可见。目标所在后续页可先加载，中间缺页仍可继续补齐；页号仅作提示，目标因热度变化移位时继续查找正常分页。手机定位使用外层 overlay card 滚动，图片预留尺寸，用户主动滚动或交互会停止后续滚动校准。目标删除时保留正常列表并显示简短提示。居中调整再次通过 44 项测试和生产构建，桌面深页及手机图片夹具均已验证；居中定位截图为 `.impeccable/review/notification-comment-center-desktop.jpg`。先前详情截图 `.impeccable/review/notification-detail-context-desktop.jpg`、`notification-detail-context-mobile.jpg` 保留为历史记录。默认、深页、手机图片和删除场景已完成合成数据验证；深页入场动画中间帧截图不作为视觉验收图。先前详情和背景滚动验证截图保留为历史记录。

这些测试没有启动服务、占用新增端口、停止用户服务或执行迁移。前端复用已有 Vite 服务热更新；后端源码及编译产物已更新，用户需要重启 IDE 中的通知服务和评论服务，使新增预览与定位字段生效。夹具验证不等于真实账号、后端和 MQ 的完整联调，真实授权、网关转发、SSE 心跳与多实例投递需单独验证。
