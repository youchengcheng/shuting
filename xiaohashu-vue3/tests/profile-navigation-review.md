# 个人主页入口回归修复

用户原有 Edge 页面 `http://localhost:5173/notifications` 已复现：token 存在，个人资料缓存为空，侧栏“我”显示为禁用的“正在加载个人资料”；账号菜单“我的主页”点击后仍停留在通知页。两个入口原先均要求 `profile.userId` 存在，资料查询失败后没有可进入的重试页面。

入口现使用同一个 `ownProfilePath()`。用户 ID 已知时沿用指定用户链接；未知时进入 `/user/profile`。Profile 路由的 ID 为可选参数，本人页面向既有 `/user/profile` API 发送空对象，由服务端登录上下文确定本人。

页面展示资料加载、失败重试和登录提示。本人资料成功后修复当前会话的资料缓存；访问他人资料保留登录用户身份。切换账号、用户路由或退出页面会作废并取消旧资料请求，迟到结果不能覆盖新的账号。主页的 `isSelf` 使用字符串比较 ID，编辑/关注显示共用该判断；请求笔记时保留十进制 ID 字符串。

个人主页笔记子路由支持 `/user/profile/note/:noteId` 与 `/user/profile/:userId/note/:noteId`。子路由变化不触发重复的父页资料加载。资料加载失败后两个“我”入口仍可点击。

通知 API 的 404/503 现展示“通知服务暂时不可用，请稍后重试”，保留重新加载入口；重复的摘要错误不再与列表错误同时显示。本次前端修复没有解决后端服务接入。

验证：`npm test` 20/20 通过；`npm run build` 通过（201 个模块）；`git diff --check -- xiaohashu-vue3` 通过。新增路由、资料恢复、重试、身份隔离、ID 类型与通知错误回归测试。

修复后实页视觉验证未执行：原 CUA 的只读复核及结束摘要调用均遇到自动审批系统 `content-blocked` 审核失败，动作未执行。真实 HTTP 联调由主任务通过正常网关链路验证，结果由主任务记录。
